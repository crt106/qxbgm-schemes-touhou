# TH01 灵异传·原版全曲替换（修复版）

适用于 QxBgmManager 0.1.2 及以上版本。覆盖正式 TH01 地图的 15 首音乐。

1. 退出原神，用新版 app 卸载旧版 TH01 方案。
2. 在方案市场刷新后安装本方案，或在方案管理中打开 `th01-original-full-v2.qxbgmzip`。
3. 进入 TH01 地图，音乐选项选择“原神”。

音频来自原作音序数据和原驱动录音。本版修正单声道 WEM 的声道配置；保持原速、压缩音频数据、时长与上一份已验证修复包一致。

验证：15 首全长参考解码及游戏解码指令隔离执行一致，合成音乐包安装和恢复通过。用户已反馈当前修复版可以使用；未将离线测试视作所有场景的实机验收。

本方案只替换本地音乐文件，不修改地图。现有《逐火如弦》对应播放区间为 104 秒；《献给神明的魂魄》约 123 秒，地图时长仍需单独调整才能完整循环。

TH01 与 TH08 方案共用音乐编号 10009、10020；切换地图方案前请卸载前一方案，避免覆盖冲突。更新或修复原神前请恢复音乐。
